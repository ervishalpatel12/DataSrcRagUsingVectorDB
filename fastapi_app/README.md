# PineVector: Modular FastAPI & Pinecone Vector Database Service

A production-grade, modular REST API for vector database operations using **FastAPI** and **Pinecone**, engineered for high-throughput semantic search applications.

## Key Features
- **Separated Pipelines**: Independent endpoints for `/upload`, `/upgrade`, and `/retrieve`.
- **Modular Package Structure**: Clean separation of `core`, `models`, `services`, and `api/v1/endpoints`.
- **Business Logic Markdown**: Every package folder contains an accompanying `.md` detailing architectural rationale, edge cases, formulas, and performance SLAs.
- **Resilient Embeddings**: Automatic vector embedding via Gemini `@google/genai` or Pinecone inference with deterministic local fallback.
- **Enterprise Pinecone Semantics**: Multi-tenancy namespace isolation, rich metadata filtering (`$eq`, `$in`, `$gt`), and cosine distance calculation.

## Quickstart

### 1. Installation
```bash
python -m venv venv
source venv/bin/activate  # Or `venv\Scripts\activate` on Windows
pip install -r requirements.txt
```

### 2. Configure Environment
Create `.env` in `fastapi_app/`:
```env
PINECONE_API_KEY=your_pinecone_api_key
PINECONE_ENVIRONMENT=us-east-1
PINECONE_INDEX_NAME=semantic-search-index
GEMINI_API_KEY=your_gemini_api_key
```

### 3. Run FastAPI Server
```bash
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```
Open interactive Swagger UI at: `http://localhost:8000/docs`.

## API Usage Examples

### 1. Upload Documents (`POST /api/v1/upload`)
```bash
curl -X POST "http://localhost:8000/api/v1/upload" \
  -H "Content-Type: application/json" \
  -d '{
    "documents": [
      {
        "id": "doc_arch_01",
        "text": "Vector databases store dense numeric representations of text generated by deep neural networks to allow semantic search.",
        "metadata": { "category": "engineering", "author": "Alice" }
      }
    ],
    "namespace": "knowledge-base",
    "auto_chunk": true,
    "chunk_size": 500,
    "chunk_overlap": 80
  }'
```

### 2. Upgrade Existing Vector (`PUT /api/v1/upgrade`)
```bash
curl -X PUT "http://localhost:8000/api/v1/upgrade" \
  -H "Content-Type: application/json" \
  -d '{
    "items": [
      {
        "id": "doc_arch_01_c0",
        "new_text": "Vector databases store high-dimensional dense embeddings to perform fast approximate nearest neighbor (ANN) search.",
        "metadata_patch": { "version": "2.0", "reviewed": true },
        "namespace": "knowledge-base",
        "merge_metadata": true
      }
    ]
  }'
```

### 3. Retrieve by Semantic Meaning (`POST /api/v1/retrieve`)
```bash
curl -X POST "http://localhost:8000/api/v1/retrieve" \
  -H "Content-Type: application/json" \
  -d '{
    "query_text": "How do embeddings enable nearest neighbor search?",
    "namespace": "knowledge-base",
    "top_k": 3,
    "filter": { "category": { "$eq": "engineering" } },
    "min_score": 0.60
  }'
```
